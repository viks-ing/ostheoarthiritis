# KneeWise Platform

**KneeWise** is an AI-powered knee osteoarthritis (KOA) screening and rehabilitation platform designed for clinical decision support in community health and clinical settings.

## System Architecture

```text
KneeWise/
├── ml/            # Complete Machine Learning pipeline (PyTorch, ONNX, Evaluation)
└── backend/       # Future Django / REST API backend
```

Please refer to [`ml/README.md`](ml/README.md) for full documentation on model training, dataset setup, hardware optimizations, and inference.
